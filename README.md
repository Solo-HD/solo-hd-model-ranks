# Solo_HD model ranks

Quality ranks and specs for the KIE image and video models, read by **Solo_HD Studio** at start-up.

| File | What it holds |
|---|---|
| `ranks.json` | Per task type (Text to Image, Image to Image, Text to Video, Image to Video): KIE model id → rank position, score, source, label |
| `model-specs.json` | KIE model id → longest clip (s), top quality, sound |
| `meta.json` | When it was last updated, counts, sources |

Updated weekly from the LMArena and Artificial Analysis leaderboards and the KIE catalogue.
Data only: no keys, no personal files.
